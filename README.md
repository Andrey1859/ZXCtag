# ZXCtag

Плагин Paper/Arclight 1.21.1 (Kotlin): префикс класса и жёлтый уровень.

## Сборка

```
./gradlew build
```

Готовый файл: `build/libs/zxctag-1.0.0.jar`  
Класть в папку **`plugins`**.

## Команда

```
/zxc <ник> <класс> <статус> <лвл> <ус>
/prefix <ник> <класс> <статус> <лвл> <ус>
```

`/zxc` — тот же префикс с буквами ZXC. `/prefix` — без ZXC.

Права: `zxctag.zxc` и `zxctag.prefix` (по умолчанию op). Tab подсказывает ник, класс, статус, лвл и УС.
