# ZXCtag

Плагин Paper/Arclight 1.21.1 (Kotlin): префикс класса, жёлтый уровень и HP над игроком.

## Сборка

```
./gradlew build
```

Готовый файл: `build/libs/zxctag-1.0.0.jar`  
Класть в папку **`plugins`**.

## Команда

```
/zxc <ник> <класс> <статус> <лвл> <ус> <хп>
```

Право: `zxctag.zxc` (по умолчанию op). Tab подсказывает ник, класс, статус, лвл, УС и хп.
