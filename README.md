# ZXCtag

Плагин Paper 1.21.4 (Kotlin): префиксы игроков и пакетные NPC со скином Java-аккаунта.

## Сборка

```sh
./gradlew build
```

Готовый файл: `build/libs/zxctag-1.0.0.jar`. Поместить в папку `plugins`.

## Префиксы

```text
/zxc <ник> <класс> <статус> <лвл> <ус>
/prefix <ник> <класс> <статус> <лвл> <ус>
```

`/zxc` — префикс с буквами ZXC, `/prefix` — без ZXC.

Права: `zxctag.zxc` и `zxctag.prefix` (по умолчанию op). Tab подсказывает ник, класс, статус, уровень и УС. В начале префикса плагин выводит символ U+E001; клиентский мод заменяет его пиксельной иконкой лука `bow.png`.

## NPC со скином по нику

Выполнить команду в точке, где должен стоять NPC:

```text
/spawnnpc <имя_NPC> <Java-ник_скина> <класс> <статус> <лвл> <ус>
/rpg spawnnpc <имя_NPC> <Java-ник_скина> <класс> <статус> <лвл> <ус>
```

Например: `/spawnnpc Guard Notch лучник premium 50 10`. Имя NPC и ник скина должны содержать от 1 до 16 латинских букв, цифр или `_`. Используются те же значения, что и в `/zxc`/`/prefix`: классы `бард`, `лучник`, `заклинатель`, `некромант`, `жрец`, `шут`, `джокер`, `мушкетер`, `хранитель`; статусы `none`, `premium`, `admin`; уровни `1`, `5`, `10`, `20`, `30`, `50`, `100`; УС `0`, `1`, `5`, `10`, `20`. Для NPC формируется такой же ZXC-префикс над именем. Команда доступна игрокам с правом `zxctag.spawnnpc` (по умолчанию op). Подкоманда `/rpg spawnnpc` перехватывается отдельно, не заменяя и не ломая остальные команды `/rpg` от других плагинов.

Скин ищется через API Mojang. Запрос выполняется в фоне, поэтому серверный поток не блокируется. В профиль пакетного игрока добавляется исходное подписанное свойство `textures` Mojang; проверяется, что адрес текстуры ведёт на `textures.minecraft.net`. Снимок места, стандартной позы, углов корпуса/головы, класса, статуса, уровня, УС и данных скина сохраняется в `plugins/ZXCtag/npcs.yml`; NPC восстанавливаются после перезапуска вместе с префиксом.

NPC — только отображаемый клиентам пакетный игрок, не подключённый аккаунт. Он создаётся в текущем мире и точке команды; серверу нужен доступ к API Mojang. NPC неподвижен и сам не обрабатывает взаимодействия. Внутренний адаптер рассчитан на Paper 1.21.4.

### Предмет в руке NPC

Подойдите к NPC на расстояние до 5 блоков и используйте:

```text
/npcitem [main|off] [имя_NPC]
/rpg npcitem [main|off] [имя_NPC]
```

Без аргументов предмет из основной руки копируется ближайшему NPC в основную руку. `/npcitem off` копирует предмет из второй руки игрока во вторую руку NPC. Имя NPC необязательно; его можно указать, например `/npcitem Guard off`, но проверка близости всё равно действует. Предмет копируется для отображения и остаётся у игрока. Право: `zxctag.npcitem` (по умолчанию op); экипировка сохраняется в `npcs.yml`.
