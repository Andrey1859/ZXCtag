# NpcSkin

Самостоятельный серверный плагин для **Paper 1.21.4** (Java 21), который создаёт NPC в виде
игрока со скином по Java-нику.

- Без клиентского мода, Citizens, админки и базы данных.
- NPC хранятся **только в памяти**: после перезапуска сервера они исчезают.
- Создание только из игры, обе команды только для OP.

## Команды

```
/npc <Java-ник>     создаёт неподвижного NPC на месте игрока со скином указанного
                    аккаунта; копируются повороты корпуса, головы и наклон взгляда,
                    при приседании создателя NPC приседает
/npc clear          удаление всех NPC плагина
```

## Сборка

Требуется JDK 21 и доступ к интернету (Gradle 9.4.1 скачивается через wrapper,
Paper и paperweight-userdev — из репозиториев PaperMC/Maven).

```bash
cd npc-skin
./gradlew build          # Windows: gradlew.bat build
```

Результат: `npc-skin/build/libs/NpcSkin-1.0.0.jar`.

## Установка

1. Скопировать `NpcSkin-1.0.0.jar` в папку `plugins/` сервера.
2. Запустить сервер (или перезапустить, если он уже был включён).
3. Дать OP игроку и в игре выполнить, например:

```
/npc Notch
```

Обычный клиент без модов должен видеть NPC со скином аккаунта `Notch`.

## Как это работает

- `NpcPlugin` — основная точка входа: регистрация команд/событий, менеджер, очистка при отключении.
- `NpcCommand` — проверка прав и ника, захват позиции/поворотов/приседания, **асинхронная**
  загрузка скина (игра не блокируется), создание NPC на основном потоке; если игрок вышел
  или плагин выключен — создание не выполняется.
- `SkinResolver` — два GET-запроса к Mojang (profile → uuid → подписанные textures),
  тайм-ауты 10/15 сек, ограничение ответа 64 КиБ, обработка 404/429/тайм-аутов/некорректного JSON.
  `value` и `signature` передаются **без изменения**.
- `SkinUrlValidator` — проверка URL скина (http/https, `textures.minecraft.net`,
  `/texture/{hex}`; отклоняются userinfo/port/query/fragment).
- `NpcManager` — реестр NPC в памяти: UUID профиля, ServerPlayer, ID сущности, мир, данные для повторного показа.
- `NpcPacketAdapter` — NMS: GameProfile с уникальным именем (≤16 символов) и property
  `textures`, ServerPlayer, координаты/повороты/поза/приседание, mask `0x7F` всех слоев скина,
  порядок пакетов: player info → add entity → entity data → head rotation + orientation;
  очистка — removal entity + player info.
- `NpcListener` — показ NPC при входе и при смене мира.

Пакеты отправляются только с основного потока. Профиль держится вместе с NPC до
загрузки скина клиентом. Разные NPC с одним скином — разные UUID и разные идентификаторы.

## Ограничения

- Поддерживается только Paper 1.21.4 (direct NMS adapter, без reflection и рефлекшена).
- Масштаб: до 100 NPC одновременно (в памяти).
- AI, ходьба, квесты, сохранение — не поддерживаются (по требованиям).
