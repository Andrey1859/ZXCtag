# ZXC Textures

Клиентский **Fabric-мод для Minecraft 1.21.1**: заменяет выбранные символы в любом тексте игры
(ник, префикс, чат, Tab, таблички) на картинки.

В моде нет кода: внутри только шрифт и PNG. Ставится игрокам, на сервер ничего класть не нужно.

## Куда что класть

| Что | Куда |
| --- | --- |
| Картинки (PNG) | `src/main/resources/assets/zxctextures/textures/font/` |
| Список символов и привязка к картинкам | `src/main/resources/assets/minecraft/font/default.json` |

## Как привязать картинку к символу

Каждый символ — один блок в `default.json`:

```json
{
  "_symbol": "奤  U+5964",
  "_note": "ВПИШИ ИМЯ КАРТИНКИ В file -> zxctextures:font/ИМЯ.png",
  "type": "bitmap",
  "chars": ["\u5964"],
  "file": "",
  "height": 8,
  "ascent": 7
}
```

1. Положи PNG в папку для картинок.
2. В поле `file` впиши `zxctextures:font/ИМЯ.png`, например `"file": "zxctextures:font/us.png"`.
3. Пересобери мод.

### Иконка лука

Для пиксельной иконки лука зарезервирован символ **U+E001** из Private Use Area. Картинка `bow.png` подключена в `default.json`; плагин ZXCtag выводит этот символ в начале префикса. Без мода U+E001 может отображаться как пустой/неизвестный символ.

Правила для имени файла: только латиница в нижнем регистре, цифры, `_`, `-` и расширение `.png`.

Поля `_symbol` и `_note` нужны только для подсказки, в мод они не попадают.

## Что делает сборка

`default.json` — это **список**, а не готовый шрифт. Сборка (`generateFont`) читает его и делает
настоящий шрифт для мода:

- запись с пустым `file` **пропускается** (картинки ещё нет, символ остаётся обычным);
- запись с заполненным `file` проверяется: файл на месте, имя написано в точности как у файла,
  это настоящий PNG не больше 256×256, `ascent` не больше `height`;
- если что-то не так, сборка **останавливается с понятным сообщением**.

Это нужно, потому что игра не прощает ни одной ошибки в шрифте: если хоть одна запись не загрузится
(пустое имя, нет файла, битый PNG), игра отбрасывает **весь** шрифт и показывает чёрный экран.
Поэтому пустые записи нельзя класть в мод как есть.

Размер символа: `height` — высота картинки в игре (8 = как высота букв), `ascent` — подъём над строкой
(не больше `height`). Картинка любого размера до 256×256, лучше квадратная (16×16, 32×32).

## Что нужно игроку

- Fabric Loader для 1.21.1
- Fabric API
- сам мод `zxctextures-1.0.0.jar` в папку `mods`

## Сборка

В папке `textures`:

```
./gradlew build
```

(Windows PowerShell: `.\gradlew.bat build`)

Готовый файл: `build/libs/zxctextures-1.0.0.jar`

Если после запуска игры что-то не так, смотри `logs/latest.log` в папке Minecraft.
